# LOAN-simulator
https://rtac1998.github.io/LOAN-simulator/
住宅ローンの返済額をシミュレーションできる、ブラウザで動く単一HTMLファイルの計算ツールです。

## できること

- **返済額の計算**: 元利均等・元金均等の2方式に対応
- **ペアローン**: お二人分の借入額・年収を個別に入力し、合算して計算
- **ボーナス払い**: 年2回のボーナス返済を考慮した計算
- **住宅ローン控除**: 性能区分（認定住宅／ZEH水準／省エネ基準／その他）・築年数・耐震基準に応じた控除額を計算し、控除適用後の実質負担額を表示
- **頭金の比較**: 頭金を変えた場合の毎月の負担額・総返済額の違いを一覧で比較
- **返済負担率のチェック**: 年収に対する年間返済額の割合を表示し、金融機関の目安を超える場合は注意を表示
- **PDF保存**: ブラウザの印刷機能を使って計算結果をPDFで保存

## 使い方

`index.html` をブラウザで開くだけで動作します。ビルドや依存パッケージのインストールは不要です。
https://rtac1998.github.io/LOAN-simulator/

## 技術構成

素の HTML / CSS / JavaScript のみで構成されており、フレームワークやライブラリへの依存はありません。

## 注意事項

住宅ローン控除の計算は、令和8年度税制改正後（2026年4月1日施行、租税特別措置法第41条）の制度を前提としています。実際の適用可否・控除額は税理士等の専門家にご確認ください。
